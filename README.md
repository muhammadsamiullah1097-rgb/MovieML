# MovieML Studio

A university ML midterm project based on **The Movies Dataset** from Kaggle. It contains a FastAPI backend, a responsive HTML/CSS/JavaScript frontend, selectable ML models, model comparison, preprocessing tools, feature analysis, and two movie recommendation methods.

## Download the source

Download **[MovieML_Source_Code.tar.xz](MovieML_Source_Code.tar.xz)** from this repository and extract it with 7-Zip (right-click, 7-Zip, Extract Here). It contains the project source code, frontend, documentation, and tests.

## Dataset setup

Download the dataset from Kaggle:

https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset

Extract these four CSV files into the extracted project's `backend/data/raw/` folder:

- `movies_metadata.csv`
- `ratings_small.csv`
- `keywords.csv`
- `links_small.csv`

Large Kaggle CSVs and trained model binaries are not stored in this Git repository. After adding the CSVs, the project can create its model artifacts locally.

## Run locally (Windows, macOS, or Linux)

Open a terminal in the extracted project folder and run:

```bash
cd backend
python -m venv .venv
```

Activate the environment:

**Windows PowerShell**
```powershell
.venv\Scripts\Activate.ps1
```

**macOS / Linux**
```bash
source .venv/bin/activate
```

Install the libraries:

```bash
pip install -r requirements.txt
```

Train the reference models (first run, or when model files are missing):

```bash
python train_models.py
```

Start the FastAPI backend:

```bash
uvicorn app.main:app --reload
```

Open the website:

http://127.0.0.1:8000

API documentation:

http://127.0.0.1:8000/docs

## ML modules

- **Classification:** 12 algorithms for movie rating-tier classification.
- **Regression:** 8 algorithms for predicting TMDB vote average.
- **Text classification:** 2 algorithms for primary-genre prediction.
- **Preprocessing:** missing-value handling, duplicate checks, encoding, scaling, SMOTE, RFE, and PCA.
- **Recommendations:** content-based and collaborative filtering.

## Project contents

The source archive contains the `backend/`, `frontend/`, `docs/`, and `tests/` folders, plus `requirements.txt`, `train_models.py`, and the project README.

The CSVs are downloaded separately from Kaggle as shown above. Trained model files are generated by `python train_models.py`.
